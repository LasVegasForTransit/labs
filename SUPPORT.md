# Support

Las Vegans for Better Transit maintains LVBT Labs. Experiments span active, deprecated, retired, and
graduated states; the catalog identifies the state of each public project.

## Public support

### Product bugs and ideas

The [issue tracker](https://github.com/LasVegasForTransit/labs/issues) accepts reproducible bugs,
project ideas, usage questions, and documentation problems. Reports name the affected lab and public
path.

### Organization questions

[hello@lasvegasfortransit.org](mailto:hello@lasvegasfortransit.org) handles questions about Las
Vegans for Better Transit and its stewardship of Labs.

### Media inquiries

The organization website publishes the current [media contact](https://lasvegasfortransit.org).

## Private security reports

Exploitable vulnerabilities follow the private process in [Security](SECURITY.md). Public issues do
not contain vulnerability details.
