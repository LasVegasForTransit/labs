# TransitFunding

TransitFunding explains how Southern Nevada pays for transportation, what a useful transit network
costs, and which policy changes close the gap. The interactive publication runs at
`labs.lasvegasfortransit.org/transit-funding`.

## Development

Run the project with `pnpm lab dev transit-funding`. The command starts the Vite and React
application at its production base path. `pnpm check` validates the fiscal model, sources, visual
palette, accessibility, archive build, and Worker output.
