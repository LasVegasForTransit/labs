# Initial catalog launch

The home catalog was deployed to <https://labs.lasvegasfortransit.org/> on September 5, 2026 UTC.
TransitMapper is listed; Transit Funding remains unlisted and was not deployed.

## Verification

A fresh local clone passed `pnpm bootstrap`, `pnpm preflight`, and `pnpm check` with Node 24.20.0
and pnpm 11.25.0. The working repository passed its checks and production builds. Browser tests
passed 19 scenarios; the desktop-only sticky brand scenario was skipped on mobile.

Generated Astro and React projects passed lint, type checks, unit tests, production and archive
builds, and desktop/mobile Worker route-refresh tests in a disposable checkout. This verifies
scaffolding, not the full retirement or migration lifecycle.

Live requests confirmed successful DNS resolution, trusted TLS, HTTP 200 on home, and HTTP 404 on an
unknown path. Desktop and mobile production screenshots were inspected. Both project and brand
images loaded, and no browser page errors were observed. Response headers include
`X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`, and `X-Frame-Options`.

The first Worker version was `2ae50b24-3d42-48d2-a784-627b60841961`. A second deployment,
`1c4deaba-ee53-4c3f-ba65-176ae596cad5`, was rolled back to the first version. Cloudflare confirmed
100% traffic on the restored version; a subsequent HTTPS request returned 200.

## Outstanding work

GitHub Actions has no dedicated deployment token. The production environment requires
`CLOUDFLARE_API_TOKEN` with Workers deployment permissions. The Wrangler OAuth credential stays
local and is not suitable for copying into CI.

Web Analytics configuration is blocked by account permissions: the site-list API returned HTTP 403
with Cloudflare error 10000. No analytics property was provisioned, and no tracker was added.

The main website footer link is prepared locally and passed that repository's checks. It is not
published; the required commit and pull-request workflow still needs explicit authorization.

Production slug-route overrides have not been exercised against a separately deployed lab Worker.
Local Worker routing tests pass. Provisioning reconciliation, automated PR previews, deprecation,
retirement, and migration remain separate platform work; this launch does not establish those
contracts as implemented.
