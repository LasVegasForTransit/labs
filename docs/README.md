# LVBT Labs documentation

The documentation tree separates repository ownership from project ownership. Platform architecture,
contracts, and operations live at the root. Product knowledge stays beside the lab that owns it.

Diátaxis provides the document types: tutorials teach, how-to guides complete a task, reference
records facts and contracts, and explanation develops understanding. Domains such as development,
operations, product, and security form the first directory level.
