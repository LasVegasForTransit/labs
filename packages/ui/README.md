# LVBT UI

`@lvbt/ui` contains small accessibility and lifecycle primitives shared across Labs. It does not own
navigation, page composition, application state, or business logic.

The UI package provides accessible foundational controls for Astro and React. Controls share
interaction behavior and brand styling while leaving navigation, state, workflows, and domain logic
inside each application.

The repository [shared UI reference](../../docs/development/reference/brand-and-ui.md) defines
package ownership and required behavior.
